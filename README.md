# EventSphere

Multi-agent venue booking and digital ticketing platform — IT4123 ICA02.

## Run locally
\`\`\`
pip install -r requirements.txt
uvicorn app.main:app --reload
\`\`\`

## Environment variables
Copy `.env.example` to `.env` and fill in `SECRET_KEY`.
